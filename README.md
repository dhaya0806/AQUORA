## 📖 About the Project

Access to suitable water treatment equipment is important for homes, businesses, and industries. AQUORA aims to make product discovery easier through a modern, responsive storefront focused on the Indian market.

The project brings different water purification product categories into one catalogue, helping visitors explore available options and identify solutions that fit their requirements.

## 🎯 Project Objectives

- Build a modern and user-friendly water treatment catalogue.
- Organize products by application and category.
- Make product discovery easier through filtering.
- Present product information in a clear format.
- Provide a foundation for customer enquiries and quotation requests.
- Create a responsive interface for desktop and mobile users.

## ✨ Features

- 💧 Water treatment product catalogue
- 🏠 Residential water purifier listings
- 🏭 Commercial and industrial product categories
- 🔎 Product category filtering
- 🇮🇳 India-focused product selection
- 🖼️ Product image support
- 💰 Product price information where available
- 📩 Request-a-Quote concept
- 📱 Responsive storefront design
- 🎨 AQUORA branding and modern visual styling

*Note: Product availability, prices, images, and enquiry functionality may vary by listing and implementation status.*

## 🛒 Product Categories

### 1. Residential Water Purifiers
Water purification products intended for home use.

### 2. Commercial Water Treatment
Solutions intended for businesses and commercial environments.

### 3. Industrial Water Treatment
Industrial water purification and reverse osmosis (RO) equipment for larger applications.

Other water treatment equipment and related products included in the catalogue.

## ⚙️ Getting Started

Follow these steps to run AQUORA on your computer.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/dhaya0806/AQUORA.git
```

### 2. Navigate to the Project

```bash
cd AQUORA
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Open the local URL displayed in your terminal, usually:

`http://localhost:5173/`
